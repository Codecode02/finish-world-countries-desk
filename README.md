# World Countries Desk

A responsive single-page application (SPA) built with **React** and **Vite** that displays information about all countries using the [REST Countries API](https://restcountries.com/).  
It includes features like **search**, **region and subregion filtering**, **independence toggle**, **sorting**, **pagination**, and **mobile support** with modal dialogs for detailed view.

## Features

- Search by name, capital, language, currency, or area
- Filter by region and subregion
- Toggle to show only independent countries
- Sort by any column (name, capital, region, area, etc.)
- Responsive UI with mobile-friendly card layout
- Modal dialog with detailed country info
- Unit tests for key components with React Testing Library

## Project Structure

- `public/` – Static assets  
- `src/` – Main source directory  
- `src/components/` – Reusable UI components  
- `src/components/Header/` – Header component for filters and search  
- `src/components/Header/Header.jsx` – Header component file  
- `src/components/Table/` – Table and mobile card list  
- `src/components/Table/Table.jsx` – Table/country list component file  
- `src/App.jsx` – Main application logic  
- `src/main.jsx` – React DOM entry point  
- `README.md` – Project documentation  
- `package.json` – Project dependencies and scripts  
- `vite.config.js` – Vite build configuration  

## Getting Started
